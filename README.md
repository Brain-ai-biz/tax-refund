# צייד החזרי המס

**בודקים אם מס הכנסה חייב לך כסף, מתוך טופסי ה-106 של השנים האחרונות.** מביאים את הטפסים, עונים על כמה שאלות קצרות, ומקבלים דף מונפש: הטפסים נפרשים לפי שנים, השנים שבהן נוכה ממך יותר מדי נדלקות, ומונה שקלים רץ אל ההחזר המשוער. מתחת: למה, מה לצרף, ואיפה מגישים. בחינם, בלי רואה חשבון.

## מה צריך להביא
**טופס 106 לכל שנה מ-2020 עד 2025, מכל מעסיק שעבדת אצלו באותה שנה** (שני מעסיקים בשנה = שני טפסים). מי שקיבל דמי אבטלה, דמי לידה או תגמולי מילואים מביא גם את האישור השנתי למס הכנסה מביטוח לאומי. אחר כך עונים על כ-8 שאלות קצרות, רובן כן או לא.

### איך מורידים את טופסי ה-106, צעד אחרי צעד
1. נכנסים לאזור האישי באתר רשות המסים: https://www.gov.il/he/service/personal_area_taxes ולוחצים "לכניסה למערכת".
2. בפעם הראשונה נרשמים. זה בחינם: עונים על כמה שאלות אימות (למשל פרטי כרטיס אשראי, לאימות בלבד ולא לחיוב) ומשאירים טלפון ומייל.
3. באזור האישי בוחרים "טופסי 106".
4. בוחרים שנה ומורידים כל טופס כקובץ PDF. חוזרים על זה לכל שנה מ-2020 עד 2025.
5. משאירים את הקבצים בתיקיית ההורדות (Downloads). הכלי מחפש שם לבד.

טופס חסר באזור האישי? מבקשים אותו ממחלקת השכר של המעסיק. גם מעסיק שכבר עזבת חייב לתת.

## פרטיות
- ב-Claude Code ובקודקס: הטפסים נקראים במחשב שלך. סקריפט מקומי מוציא מהם את הטקסט ו**מוחק מספרי תעודת זהות לפני כל דבר אחר**, כך שמספר הזהות לא יוצא מהמחשב. השם, שם המעסיק והסכומים כן מגיעים ל-Claude או לקודקס כדי לחשב, כמו בכל שיחה. הדף נשמר אצלך ולא נשלח לשום מקום.
- ב-ChatGPT: הקבצים עולים לשרתים של OpenAI, כמו כל קובץ שמעלים לצ'אט. מספרי הזהות נמחקים לפני הניתוח, אבל הקובץ עצמו כבר עלה. מי שרוצה שהכול יישאר במחשב, עדיף Claude Code או קודקס.

## כמה אפשר לסמוך על זה
**זו הערכה ולא חישוב להגשה ולא ייעוץ מס.** המערכת מחשבת מחדש את המס של כל שנה לפי המדרגות ונקודות הזיכוי של אותה שנה, ומשווה למה שנוכה ממך. כל ערך מקושר למקור רשמי או מוכר (כל זכות, רשות המסים). הטווח משאיר מרווח ביטחון, ואת הסכום הסופי קובעת רשות המסים אחרי ההגשה.

מה לא נספר בסכום (ומופיע כ"ייתכן שמגיע לך עוד"): יישוב מזכה, הפקדה עצמאית לפנסיה, הורה יחיד, מוגבלות, עלייה ושוק ההון.

## הפרומפט ל-ChatGPT (להעתקה)
אני מעלה לך את הקובץ tax-refund.zip (הכלי "צייד החזרי המס") ואת טופסי ה-106 שלי, ואם יש, גם אישורים שנתיים מביטוח לאומי. אני רוצה לדעת אם מס הכנסה חייב לי כסף, ולקבל בסוף את הדף המונפש עם התוצאה.

עבוד עם כלי הפייתון שלך, כך:
1. חלץ את tax-refund.zip אל /mnt/data (נוצרת התיקייה /mnt/data/tax-refund) וקרא את הקובץ /mnt/data/tax-refund/SKILL.md. פעל לפיו בדיוק, כולל חמשת כללי הברזל. בכל מקום שכתוב שם python3 scripts/tax_refund.py, הרץ python3 /mnt/data/tax-refund/scripts/tax_refund.py. תיקיית העבודה (RUN) היא /mnt/data/run.
2. הרץ extract על כל קובצי ה-PDF שהעליתי (לא על מה שבתוך ה-zip). מכאן עבוד רק מהטקסט הנקי שב-/mnt/data/run/text, שבו מספרי הזהות כבר נמחקו. אל תצטט ואל תציג לי את התוכן הגולמי של הטפסים.
3. ודא איתי את המספרים מכל טופס, ואז שאל אותי את השאלות מ-SKILL.md בהודעה אחת קצרה.
4. אחרי שעניתי: הרץ check, estimate ו-report (בלי --open), ותן לי קישור להורדה של /mnt/data/run/report.html. את הקובץ פותחים בדפדפן במחשב או בטלפון.
5. סכם לי לפי סעיף 6 ב-SKILL.md, כולל הדיסקליימר מילה במילה.

אם לא העליתי טפסים ורק רוצה לראות איך זה נראה: הרץ demo עם --out /mnt/data/demo ותן לי להוריד את /mnt/data/demo/report.html.
דבר איתי בעברית פשוטה.
